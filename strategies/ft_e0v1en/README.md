# E0V1EN — Freqtrade, 5m, покупка просадки (только лонг)

**Ветка:** `strategy/ft-e0v1en` · **Движок:** Freqtrade (dry-run на Bybit через `adapters/freqtrade/`) и адаптер
`hope.adapters.freqtrade.runner` (та же стратегия внутри hope: бэктест-фильтр и paper без REST) ·
**Рынок:** Bybit linear USDT-перпетуалы · **Тип:** индикаторная реверсия на 5m, тейкерные входы/выходы.

## Источник

Самая популярная простая community-стратегия Freqtrade 2023–2026: [ssssi/freqtrade_strs](https://github.com/ssssi/freqtrade_strs)
(`binance/dry_run/E0V1EN.py`, 651★). Лицензия в репозитории не указана, поэтому `E0V1EN.py` здесь — **переписанная
заново** реализация тех же правил (имена индикаторов, параметры и теги сохранены; CTI считается своей функцией
вместо `pandas_ta`, у которого нет колёс под Python 3.11).

## Логика

Вход (`enter_long`), два варианта с тегами `buy_1` / `buy_new`:

| Условие | buy_1 | buy_new |
|---|---|---|
| RSI(20) падает (ниже предыдущего) | ✓ | ✓ |
| RSI(4) < | 40 | 34 |
| RSI(14) > | 42 | 28 |
| close < SMA(15) × | 0.973 | 0.96 |
| CTI(20) < | 0.69 | 0.69 |
| изменение за 24 ч в диапазоне | (−15 %, +50 %) | (−15 %, +50 %) |

Выход: trailing-стоп 0.2 % после достижения +3 % (`trailing_only_offset_is_reached`), стоп-лосс −25 %, ROI не используется
(100 %), `custom_exit`: `fastk_profit_sell` (профит > 0, тег buy_new, Stoch fastk > 84), `cci_loss_sell` (профит > −3 %,
CCI(20) > 80), `time_loss_sell_7_5` (> 7 ч и профит ≥ −5 %), `time_loss_sell_10_10` (> 10 ч и профит ≥ −10 %).
Protection: CooldownPeriod 96 свечей (8 ч) после выхода по паре. Все ордера рыночные.

Особенность оригинала сохранена: при срабатывании обоих условий тег становится `buy_1buy_new`, и проверка
`enter_tag == "buy_new"` в `custom_exit` не срабатывает.

## Запуск

```bash
# paper в hope (без ключей и REST): прогрев 600 свечей 5m с REST или из архива
uv pip install -p .venv/bin/python -e ".[freqtrade]"
hope run -c strategies/ft_e0v1en/config.yaml
# Docker: HOPE_EXTRAS=freqtrade в .env, затем docker compose up -d --build

# настоящий Freqtrade (dry-run на Bybit, FreqUI на :8080, экспорт в общий монитор)
cp strategies/ft_e0v1en/E0V1EN.py adapters/freqtrade/user_data/strategies/
cd adapters/freqtrade && cp .env.example .env   # FT_STRATEGY=E0V1EN
docker compose up -d --build

# бэктест-фильтр по архиву сделок Bybit (свечи 5m)
hope backtest -c strategies/ft_e0v1en/config.yaml --mode candles --from 2026-09-17 --to 2026-09-25 --db data/bt_ft_e0v1en.db
```

## Результаты

### Бэктест-фильтр (архив сделок → свечи 5m, 6 символов, 2026-09-17 … 25, первые сутки — прогрев)

| Набор | Свечей | Входов | Чистый PnL |
|---|---|---|---|
| BTC, ETH, SOL, XRP, DOGE, ADA | 15 552 | **0** | 0 |
| 10 волатильных альтов (1000PEPE, SUI, WIF, WLD, ASTER, PUMPFUN, 1000BONK, MOODENG, TRUMP) | 23 328 | _считается_ | — |

Офлайн-проверка сигналов на полной истории 6 мажоров подтверждает ноль входов: условие «close < 0.973·SMA(15)»
выполнилось всего 13 раз на 15 552 свечах (BTC/ETH/SOL — ни разу), а вместе с остальными фильтрами — ни разу.

### Статус

`✗ не прошла фильтр «много сделок»` — на ликвидных перпетуалах Bybit в спокойную неделю стратегия не генерирует
входов; это подтверждает оценку каталога (0.1–1 сделка/день/пара только на волатильных альтах). Ветка сохранена как
готовый стенд Freqtrade-стратегий: следующий кандидат того же класса подключается заменой файла стратегии.

## Замечания

* Стратегия рассчитана на спот Binance и «покупку страха»; на перпетуалах Bybit это лонг-only с комиссией
  0.11 % за круг (тейкер/тейкер) — цель +3 % и стоп −25 % делают частоту сделок низкой (единицы в день на 15 пар).
* В настоящем Freqtrade результаты будут чуть отличаться: dry-run исполняет рыночные ордера по стакану с
  проскальзыванием ≤ 5 %, проверяет выходы каждые 5 с; адаптер hope — на каждой закрытой свече и каждые 5 с по BBO.
